# AI Quiz

Two 10-question quizzes: AI pixel art vs real pixel art, and AI writing vs real writing. Plain HTML/CSS/JS.

Credits for every real piece are in `credits.json` and on the site's credits page. Real pixel art is by Luis Zuno (ansimuz, CC0 and CC BY 3.0) and the Dungeon Crawl Stone Soup tile artists (CC0), via OpenGameArt.org. Real passages are public-domain excerpts from Project Gutenberg. AI pixel art was generated and then converted in code only; AI passages were written by AI for this quiz.
